🟡 MAHI SHARE

Fast, simple device-to-device file transfer

1. Connect your devices

Open this page on both devices. One device creates a room; the other scans the QR code or enters the room code.

Not connected to a room yet.

Room link works only while the room creator is connected. Keep both devices on this page.

2. Send a file

Choose a room and wait for the other device to connect.

3. Received files

Received files are assembled in this browser and saved only when you click the download link.

    Privacy: File bytes are sent over an encrypted WebRTC connection when a direct route is available. The signaling server exchanges connection messages, not file contents. This starter version uses public STUN servers only; some networks require a TURN relay and may fail to connect. Do not use this demo for confidential files until you have added abuse protection and tested it carefully.
